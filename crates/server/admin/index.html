控制台使用指南

在终端中执行内置命令，快速查看服务配置与日志。

help
显示可用命令
status
查看管理面板状态
listeners
查看配置中的监听端点
check-config
校验当前配置文件
show-config
显示 TOML 配置
tail
查看最近 20 条日志
clear
清空终端输出

快捷键：⌘ / Ctrl + K 打开终端；↑ ↓ 浏览命令历史；Tab 补全命令。

重新加载配置？

重新加载会替换当前未保存的编辑。可以先导出草稿，再加载磁盘中的最新配置。
