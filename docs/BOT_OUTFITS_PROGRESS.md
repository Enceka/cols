# Bot阵营服装

2026-10-11，3.3.3.3原客户端、纯Rust后端。

房间换队原先只更新友敌关系和出生位置，Bot服装仍沿用准备时固定的client1..5/6..11阵营。现在每个Bot职业分别准备SC/TF服装，开局依据完整房间名单选择，并同步冻结实体基线。旧准备文件没有双阵营服装时仍使用原有模型字段。

准备器从本版`botClassTable.csv`与角色变体表解析两种服装，三图均无备用职业替代。重新准备时只继承原NCS模型前缀及明确注册项，避免把稍后实采中的临时玩家模型编号误当成可跨会话继承的资源。

后续将原生角色组成扩展到全部11个Bot。角色按本局职业和实际阵营冻结；个人/最终回放复用相同client身份，背包刷新不改变该身份。前三名的12..14展示副本保留显式第三人称模型，不误用玩家或另一Bot的组成。旧准备没有`character`字段时兼容原模型路径。

准备器新增`--native-characters`，从本版只读部件银行恢复一基索引，核对分组、字段顺序及性别/阵营/肤色选择位；没有匹配时拒绝生成，不替换职业。各部件共用一个原生肤色选择值。SC女牛仔原先独立选出的白肤色手部与cau头部不一致，现由同一选择值生成cau手部。模型顺序使用原生分组顺序FPA/BOO/FJA/HAN/HEA等，三图注册表各77项。
