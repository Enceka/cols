# Bot阵营服装

2026-10-11，3.3.3.3原客户端、纯Rust后端。

房间换队原先只更新友敌关系和出生位置，Bot服装仍沿用准备时固定的client1..5/6..11阵营。现在每个Bot职业分别准备SC/TF服装，开局依据完整房间名单选择，并同步冻结实体基线。旧准备文件没有双阵营服装时仍使用原有模型字段。

准备器从本版`botClassTable.csv`与角色变体表解析两种服装，三图均无备用职业替代。重新准备时只继承原NCS模型前缀及明确注册项，避免把稍后实采中的临时玩家模型编号误当成可跨会话继承的资源。
