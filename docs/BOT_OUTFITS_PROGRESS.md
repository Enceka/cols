# Bot阵营服装与原生角色组成

每个Bot职业分别准备SC／TF外观，开局按完整房间名单选择，并冻结本局实体基线。缺少双阵营字段的兼容准备仍使用已有模型，不能宣称有完整换队服装。

准备器从本版 `botClassTable.csv` 和角色变体表解析服装，继承原NCS模型前缀及明确注册项，不把采集期间临时玩家编号当作可跨会话资源。玩家外观和Bot模型槽需同时校验冲突。

## 角色组成与回放

`--native-characters` 从只读部件银行恢复一基索引，核对组、字段顺序和性别／阵营／肤色选择；无匹配就拒绝，不替换职业。所有部件共用原生肤色选择值，模型按FPA／BOO／FJA／HAN／HEA等分组顺序排列。

11个Bot按本局职业和阵营冻结角色组成，背包刷新不改变身份；个人／最终回放复用原client。前三名12..14使用明确第三人称副本，不能错用其它人物组成。第一人称衣袖／手套跟随相应变体，见[持枪模型](VIEWMODEL_PROGRESS.md)。

## 验证与边界

自动验证覆盖原始／反转队伍、部件、肤色、实体基线、临时模型排除、非法索引、多个组成与展示副本并存，以及三图真实资源包预算。测试使用实际玩家外观和Bot共同装配，不能只检查空世界。

原生两局完成最终回放→前三名→胜局结算，已出现Bot的模型与准备一致。女性Bot3最终回放实读雅典娜两件衣袖／手套及MG4，125个样本中123个匹配；切入的两个样本仍为上一帧玩家模型，不能称作零延迟切换。证据名为 `bot-native-character-live-proof.json`。

更多换队画面、男女动作、回放目标与首帧备用模型继续复核。当前原生异步加载仍有短暂回退，见[玩家外观](PLAYER_APPEARANCE_PROGRESS.md)和[复核清单](REVIEW_PENDING.md)。
