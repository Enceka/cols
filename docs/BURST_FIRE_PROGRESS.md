# 两/三/四发点射状态机

WeaponDef+0x48c的fireType2／3／4分别按本版 `0x424830` 跳转表完成2／3／4发点射。类型6及其它特殊开火、非零延迟开火仍需独立状态机，不能借普通连射代替。

`0x4248c0/0x425250`允许已开始的点射在松开扳机后继续，发数达到上限或弹匣空才结束。`0x424d13..0x424d83`在最后一发普通间隔结束后设置ready状态和200ms恢复（本版常量 `0xc857e4`），不能把资源中邻近的250ms字段猜成点射恢复时间。每发间隔沿用最终组合WeaponDef+0xd10：本机M16/M93为64ms，FAMAS为35ms。

持续按住不自动开始下一组；`0x424930`在新的按下边沿置PS+0x280 bit0，恢复结束后能接续新点射。此标志与PS+0x284发数同时保存在权威武器状态、普通快照和回放中；同步字段121/1bit，不能仅服务器记一个不可预测的计数。开始下一组清除排队标志。重复或旧时间输入不补发子弹。

弹匣不足只发剩余子弹；切枪/备用模式切换清理未完成点射，返回原枪不继续旧组。显式换弹可从firing6中断当前点射（`0x424660→0x423490`），不会先强制打完剩余发数；恢复/换弹/复活使用原有弹药状态机。

回归覆盖2／3／4发、松手继续、长按不重复、200ms恢复、新边沿排队、短弹匣、重复输入、切枪返回和显式换弹。实际Shot的时间、数量与扣弹一致；独立协议解码检查field121置位／清除，回放保存完整equipment。

隔离M16原生对局已观察发数0／1／2／3、排队位、恢复和换弹，汇总为 `burst-fire-live-proof.json`；混合ADS／R／换包输入不构成严格单次点击／长按对照。两发及FAMAS四发仍缺各自独立实机片段，声音、后坐力与完整动画继续复核。
