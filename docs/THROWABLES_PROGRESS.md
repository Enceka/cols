# 投掷物

纯Rust支持背包中标准破片、节日破片、短引信破片、高科技破片、柄式手雷及粘性手雷，以及战术烟雾弹的基础路径。`prepare_throwables.py`从本版只读武器注册采集与marketplace／档案schema派生7项定义；原始39项offhand定义保留在研究输出中，不把其它投掷物套入破片伤害。

档案的lethal／tactical正整数先减一再做物品身份和所有权校验。普通致命投掷物当前按背包的`lethalDoubleAmmo`选择1／2枚，独立于枪械子弹。其它尚未支持的战术、部署装备效果明确记录不可用，档案与库存保留。武器类型必须为原生type1、类别6；飞刀、弩、弹道刀及枪械投射物没有借用这条爆炸路径。

## 原生控制和传输

`G`为致命投掷按钮`0x4000`；使用本版`16→17→18→19→21→0`阶段及真实枪械收枪／抬枪时间。投掷物的拉环、发射延迟、动作及引信分别读取+0x70c、+0x6f0、+0xd10、+0x7ac。`0x427490`开始收枪，`0x427630`拉环，`0x4277a0`进入持有，`0x427930`开始投出，`0x427a80`产生发射事件；`0x427ff0`按+0xd7a决定持有时是否计时。标准破片为600ms拉环、129ms发射延迟、360ms投出及3500ms引信；粘性手雷为2000ms，持有时不消耗引信。

重复命令和按住按钮不重复消耗；发射时只扣一次。收枪／近战／菜单拒绝新投掷，投掷中禁止射击、切枪和开镜。快速手部能力按原生除法缩短各阶段。已拉环的手雷在死亡时掉落，已经投出的飞行实体保留到重生之后；新生命重新从背包装配数量。

PS字段53／79／109／111分别为当前offhand、引信和致命／战术武器；库存和弹匣表携带各自真实编号及数量。MISSILE type4采用本版0xc55540的61项字段表，实体1700..1707独立于人物、尸体、挂枪、弹孔和击杀栏。完整帧及已确认delta帧保留真实标量基线；回放保存飞行实体。0xce4390原生名称表中事件87为`EV_GRENADE_EXPLODE`，事件83为`EV_GRENADE_BOUNCE`；爆炸使用eType109并在包预算内优先保留。修正后的事件已实采原生爆炸效果实例；声音及完整观感仍待专门验收。

## 当前物理和判伤范围

飞行使用资源中的初速度／上抛量、服务端重力、逐8ms球形扫掠及材质反弹参数；粘性手雷可粘住静态世界碰撞。定时爆炸走单独的范围伤害，不产生子弹／爆头伤害。判伤验证存活、世界遮挡与阵营，队友免伤，玩家可受自己手雷伤害。防爆衣倍率进入服务端爆炸伤害；自杀不计击杀，扣100分，进入正常死亡、尸体和重生流程。

当前发射点为视点前8单位、碰撞球半径2，身体采用中心点与粗高度，原生完整投掷起点／速度继承、骨骼范围判伤、部分遮挡采样、滚动、动态人物碰撞及粘人未恢复。材质参数和本版资源数字已提取，完整发射消费者与所有几何边界仍须核对；不能把当前实现写成完整原生物理已验收。

## 烟雾弹

背包烟雾60005对应本版`smoke_grenade_mp`编号236，Q按钮`0x10000`走相同的原生投掷阶段和独立弹匣条目。保存的战术项只发到Q选定槽PS+0x338／field111；中间PS+0x334／field110属于独立0x8000按钮。`0x412740`允许任一选定槽中的精确武器匹配，不限制烟雾class2；库存只保留一个真实236条目，数量写hand0。600ms拉环、129ms发射延迟、360ms投出、1000ms引信；持有时不消耗引信，不产生范围伤害。致命与战术数量分别读取当前背包的doubleAmmo位，枪械弹药独立。

普通爆发使用`EV_CUSTOM_EXPLODE93`，eType115、ES+0x58保留真实起始时刻、ES.flags位0x40。持续GENERAL实体1708..1739按本版0xc525a8字段表传输隐藏模型位、武器、起止时间和INTERPOLATE位置；已确认的full／delta基线保留真实状态，支持删除及复用。原生`0x4450a0`在初始快照／重启／回放转换时根据`start<=CGTime<=end`重建效果；没有证明普通每帧会重建，因此普通新烟雾同时需要爆炸事件，不能只发GENERAL。回放中的两个时间和EV93起始时间均与视图一起重基；原生FX使用CGTime直接计时，`CGTime-delay`只是清理截止点。

实际效果`props/american_smoke_grenade_mp`包含60秒的物理弹体模型和runner子效果`smoke/smoke_grenade_11sec_mp`。GENERAL保留60001ms来自模型的1ms延迟加60000ms寿命；这是重建截止时间，不是挡视线持续时间。子效果中两个光学粒子定义通过flags0x2000进入原生遮挡球，延迟／寿命、58／41个大小与alpha关键帧均已采集。alpha的两端按原生`0x4b9eb0`作min/max插值，当前两端相同；没有将其当作增量相加。

Bot感知和每帧缓存目标过滤已接烟雾估计：采用捕获的粒子数量、延迟、寿命及曲线的范围中值，以爆发点为球心，透射率低于0.2时失去目标；烟团淡出后恢复，弹体保留不继续阻挡。该阈值、中心和范围中值是当前服务端AI近似，不是已恢复的官方Bot规则。完整随机粒子位置、速度、碰撞、原生可见度倍率／量化与几何密度仍未移植；子弹沿原有世界碰撞判伤。回放转换可能在重建后清理同武器FX，GENERAL删除也未证明会主动销毁已生成FX；实机须独立覆盖，不能以协议回归代替。

## 验证

`smoke-complete-check.log`：384项Rust、52项Python、fmt／Clippy通过。新增烟雾Q投掷／不持有计时、独立数量／所有权、无爆炸伤害、到期删除／复用、独立GENERAL字段解码、EV93标识和起始时间、回放重基、烟雾删除与新增击杀提示同帧的实体升序，以及Bot失去／恢复目标回归。覆盖真实物品与计数、引信／发射延迟、重复命令、过期／死亡唯一触发、墙体及地面碰撞、唯一爆炸、队友免伤／自杀计分，以及依据本版独立字段表读取的8种位对齐、实体复用和删除。`throwables-preparation-check.json`与提交的fixture逐字节一致。

`grenade-controlled-live-proof.json`记录`client-1791712184987`在安全屋中的两组400帧只读采样。长按G 5秒实际持续按下181帧，原生拉环22帧及持有130帧均读到`viewmodel_m67`；正引信从3478降到40ms，随后手中爆炸造成141伤害、玩家死亡，重生后恢复1枚，存活样本主枪均为30发。单次G 1.1秒读到完整16／17／18／19／21阶段、数量1→0、105帧飞行实体及`projectile_m67fraggrenade`模型；投出后的3231ms引信到时爆炸，没有消耗枪弹。另一局正常胜局结算维持12行及玩家单行；不是手雷最后击杀回放验收。

`grenade-correct-event-live-proof.json`记录`client-1791717027434`的400帧受控投出：完整阶段、数量1→0，真实`explosions/grenadeexp_default`53帧及`explosions/grenade_flash_aerial`26帧，FX池读取无错误。这验证事件87确实分配本版爆炸效果，不等于完整声音／观感验收。

`smoke-controlled-live-proof.json`记录`client-1791719470410`的400帧Q投出：真实0x10000按下27帧，16／17／18／19／21完整，战术1→0、致命保持1、健康保持100；第一人称`viewmodel_ussmokegrenade`29帧、飞行`projectile_us_smoke_grenade`23帧，持续GENERAL327帧，起止7777／67778ms。FX池读到主效果330帧、烟团子效果265帧及爆发闪光26帧，无FX读取错误；230帧光学缓冲非空，时间9233..19642ms，相对爆发约1.46..11.87秒，结束后的片段仍有主效果和持续实体。这证明烟团与弹体寿命不同，尚不是烟雾个人／最终回放验收。

`smoke-expiry-live-proof.json`独立覆盖同实验的下一局正常到期：400帧跨过GENERAL截止时间，截止前实体存在，截止后持续实体与原生主FX均消失，光学缓冲保持空；玩家存活、pm_type0、未进入回放。探针按投掷物FX名称限定记录，密集枪战不会因采集全部弹着效果超过序列化预算。完整随机烟团对应的Bot遮挡几何和阈值仍是服务端估计。

其它五种手雷的实机片段、第三人称动作、声音／爆炸效果的完整观感、动态判伤与完整手雷回放／结算仍需覆盖。启动曾在ENOSPC之后卡在Wine文件打开IPC；证书已从校验备份恢复，原始资源不变，研究副本的相同字节初始化资源及独立prefix恢复了大厅和对局。正常配置保留7500分／600000ms；当前可用prefix为`wine10-throwables-20261011`。

剩余：闪光、震撼、毒气、EMP及其技能抗性；拾荒补给；地雷／C4／奖杯等部署装备；投掷武器与其它投射物、Bot投掷策略和连杀支援。
