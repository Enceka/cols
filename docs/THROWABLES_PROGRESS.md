# 投掷物

纯Rust支持背包中标准破片、节日破片、短引信破片、高科技破片、柄式手雷及粘性手雷的基础路径。`prepare_throwables.py`从本版只读武器注册采集与marketplace／档案schema派生6项定义；原始39项offhand定义保留在研究输出中，不把其它投掷物套入破片伤害。

档案的lethal／tactical正整数先减一再做物品身份和所有权校验。普通致命投掷物当前按背包的`lethalDoubleAmmo`选择1／2枚，独立于枪械子弹。战术、部署装备及其它尚未支持的效果明确记录不可用，档案与库存保留。武器类型必须为原生type1、类别6；飞刀、弩、弹道刀及枪械投射物没有借用这条爆炸路径。

## 原生控制和传输

`G`为致命投掷按钮`0x4000`；使用本版`16→17→18→19→21→0`阶段及真实枪械收枪／抬枪时间。投掷物的拉环、发射延迟、动作及引信分别读取+0x70c、+0x6f0、+0xd10、+0x7ac。`0x427490`开始收枪，`0x427630`拉环，`0x4277a0`进入持有，`0x427930`开始投出，`0x427a80`产生发射事件；`0x427ff0`按+0xd7a决定持有时是否计时。标准破片为600ms拉环、129ms发射延迟、360ms投出及3500ms引信；粘性手雷为2000ms，持有时不消耗引信。

重复命令和按住按钮不重复消耗；发射时只扣一次。收枪／近战／菜单拒绝新投掷，投掷中禁止射击、切枪和开镜。快速手部能力按原生除法缩短各阶段。已拉环的手雷在死亡时掉落，已经投出的飞行实体保留到重生之后；新生命重新从背包装配数量。

PS字段53／79／109／110分别为当前offhand、引信和致命／战术武器；库存和弹匣表携带各自真实编号及数量。MISSILE type4采用本版0xc55540的61项字段表，实体1700..1707独立于人物、尸体、挂枪、弹孔和击杀栏。完整帧及已确认delta帧保留真实标量基线；回放保存飞行实体。0xce4390原生名称表中事件87为`EV_GRENADE_EXPLODE`，事件83为`EV_GRENADE_BOUNCE`；爆炸使用eType109并在包预算内优先保留。效果的完整观感仍待专门验收。

## 当前物理和判伤范围

飞行使用资源中的初速度／上抛量、服务端重力、逐8ms球形扫掠及材质反弹参数；粘性手雷可粘住静态世界碰撞。定时爆炸走单独的范围伤害，不产生子弹／爆头伤害。判伤验证存活、世界遮挡与阵营，队友免伤，玩家可受自己手雷伤害。防爆衣倍率进入服务端爆炸伤害；自杀不计击杀，扣100分，进入正常死亡、尸体和重生流程。

当前发射点为视点前8单位、碰撞球半径2，身体采用中心点与粗高度，原生完整投掷起点／速度继承、骨骼范围判伤、部分遮挡采样、滚动、动态人物碰撞及粘人未恢复。材质参数和本版资源数字已提取，完整发射消费者与所有几何边界仍须核对；不能把当前实现写成完整原生物理已验收。

## 验证

`grenade-final-check.log`：371项Rust、52项Python、fmt／Clippy通过。覆盖真实物品与计数、引信／发射延迟、重复命令、过期／死亡唯一触发、墙体及地面碰撞、唯一爆炸、队友免伤／自杀计分，以及依据本版独立字段表读取的8种位对齐、实体复用和删除。`throwables-preparation-check.json`与提交的fixture逐字节一致。

`grenade-controlled-live-proof.json`记录`client-1791712184987`在安全屋中的两组400帧只读采样。长按G 5秒实际持续按下181帧，原生拉环22帧及持有130帧均读到`viewmodel_m67`；正引信从3478降到40ms，随后手中爆炸造成141伤害、玩家死亡，重生后恢复1枚，存活样本主枪均为30发。单次G 1.1秒读到完整16／17／18／19／21阶段、数量1→0、105帧飞行实体及`projectile_m67fraggrenade`模型；投出后的3231ms引信到时爆炸，没有消耗枪弹。另一局正常胜局结算维持12行及玩家单行；不是手雷最后击杀回放验收。

其它五种手雷的实机片段、第三人称动作、声音／爆炸效果的完整观感、动态判伤与完整手雷回放／结算仍需覆盖。启动曾在ENOSPC之后卡在Wine文件打开IPC；证书已从校验备份恢复，原始资源不变，研究副本的相同字节初始化资源及独立prefix恢复了大厅和对局。正常配置保留7500分／600000ms；当前可用prefix为`wine10-throwables-20261011`。

剩余：闪光、震撼、烟雾、毒气、EMP及其技能抗性；拾荒补给；地雷／C4／奖杯等部署装备；投掷武器与其它投射物、Bot投掷策略和连杀支援。
