# AlphaBuild 参考范围与本版适配

参考包主要针对1.1.1.13，目标始终为3.3.3.3。源码和资料可提供协议及行为线索，不能据此宣称本版玩法通过。Rust运行核心不链接参考C/C++核心；直接移植源码须保留对应来源与许可要求。

| 参考内容 | 本版采用方式与差异 |
| --- | --- |
| Python大厅／AUTH | 128字节票据、Tiger／3DES核心以独立向量和本版消费核对；外层使用实际HTTPS JSON |
| 大厅加密 | 本版要求协议210与HKDF-SHA1／AES／HMAC，不能用旧3DES帧替代 |
| 游戏握手 | P-224、DER、公钥／cookie及准入提供线索；本版DATA使用SHA1 KDF、AES128-CTR、小端计数和包含长度的MAC |
| 档案／库存 | 本版public233／private19及6772项物品独立提取；不套用参考220／11种子和旧任务号 |
| 购买／存储 | 借鉴所有权、流水和事务边界；实际采用文件存储、共享账号锁与原子替换 |
| 移动／武器／快照 | 参考状态机、时序与模块划分；本版235项PS、字段宽度、WeaponDef及组合名重新适配 |
| GSC／玩法 | 明确标注兼容规则来源，本版资源和原生表现独立验证；参考服务运行结果不能代替 |
| patcher／旧客户端 | 地址与导入代理仅适用于其固定样本，不能作为本版补丁使用 |

目标EXE为10473472字节，SHA-256 `e3823fd6afc80fb25fa84747e6e9634707b9a0b189357a5466921cda354af37b`。参考改动EXE为20918752字节，SHA-256 `904436480938632a856b39dea73fb94c9682b5a0ebf7fa619ecd5dd5475ed3b6`；程序名相同不代表版本相同。

本版票据已获真实客户端接受；两层传输均有独立计算向量和原生交互证据，见[AUTH](AUTH_LOBBY_PROGRESS.md)和[游戏通道](GAME_TRANSPORT_PROGRESS.md)。参考固定UID、固定密钥、空成功回执和旧build常量不作为当前运行规则。

参考目录位于工作区的 `CODOL-AlphaBuild/`，不随Rust仓库分发。实际源码和本版消费者优先于参考文档中的完成描述；对未运行的参考服务不作可玩性推断。移植方法见[纯Rust适配](ALPHA_RUST_PORT_PLAN.md)，连杀公共机制见[机制适配](ALPHA_KILLSTREAK_MECHANISMS.md)。
