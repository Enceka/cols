# Bot 避让与地面接触

Bot 避让按当前可行走坡面展开位移，再复用 `Motion::step_slide` 的胶囊滑动、台阶与近距离下探。空中避让只滑动，不吸附下方平台；保留原速度和命令时钟，不额外积分重力。实际位移决定步行动画速度。

## 导航支撑

前向扫掠通过后，每隔至多12单位检查线段附近的站立胶囊支撑，允许18单位内的台阶／坡面变化。图边、接入和转向捷径共用该入口，不能把深沟上方无墙的空间当作可步行直线。跳跃边由独立规则产生，见[导航](BOT_NAVIGATION_PROGRESS.md)。

回归覆盖brush／terrain上下坡、墙面、双向台阶、空中速度／时钟、平台离开和深沟绕行。三图真实碰撞的出生连通性与后台对局无胶囊startSolid已有验证；这些不等于全部脚底视觉已贴地。

## 只读脚部检查

`--characters` 的 `ground_pose` 和 `--grounding` 读取已计算的DObj根／脚部骨骼。本版 `0x4f9750` 要求DObj+0x94匹配骨架帧 `0x078b16c8`，并检查+0x74的逐骨骼计算位；跨帧样本标为不稳定。视野外残留矩阵不能作为脚部证据，`j_ball_*`也不是精确鞋底网格。

连续模式最多10秒／200次采样，不调用游戏函数、不写内存。诊断 `captured_bot_ground_contacts` 接受 `CODOL_GROUND_PROFILE`、输出后缀 `CODOL_GROUND_CAPTURE` 和可选 `CODOL_GROUND_POSES`；后者可为单次或连续采集，只复算有效脚部到实际地图支撑的距离。

## 明确边界

复杂物件侧缘仍可能由胶囊碰到较高斜面，而双脚点射线落在更低地面，连续采样存在超过正常抬脚相位的足底间隙。该现象尚未解决；没有服务端足部IK，也不能通过统一降低人物、缩小原生胶囊或强压抬脚掩盖。

胶囊支撑、脚部骨骼与鞋底观感分别判断。后续复核需跟随同一Bot记录路线、位置、支撑面和连续步态，见[复核清单](REVIEW_PENDING.md)。
