# 原生地图资源准备

正常游玩使用已完成的准备文件；`--resource-capture-map`是显式、单图的本地资源采集入口，要求本版真实团队竞技身份、原生自建房策略和认证准入。未提供本图初始化文件时只建立传输；提供本图资源计算出的元数据时发送初始化gamestate，不发布玩法快照，不使用其它图的CRC或世界。可靠控制消息正常读取，不适用的有界移动段忽略；不会用虚构playerState基线解码或应用移动。正常对局保持完整输入校验。

原生箭头选图后读取本图NCS与MapEnts，按本版排序／去重／种子计算CRC，再发送本图最小元数据初始化。客户端确认CRC后只读采集碰撞、武器、模型、动画和材质；正式TDM准备仍要求初始化CRC、对应碰撞、至少6+6真实出生点以及角色／武器绑定。碰撞探针按本版`coMapList.csv`的`pvp`／`war`身份检查路径。资源阶段9的武器导出另要求NCS已初始化，并保留真实阶段、地图和CRC；运行时核对地图一致。首个玩家快照前BG动画上下文可能不存在，此时使用已捕获的渲染动画银行；有BG银行时仍优先使用它，不使用未知或未捕获的编号。

新增图的小地图必须有本图材质证明：客户端／捕获SHA、本图路径和CRC、准确材质名、非默认渲染判据及真实贴图尺寸。原有三图的已核验材质绑定保留。缺少证明、默认图片、16×16回退或不同地图／CRC均拒绝。Bot模型按本图重新编号，玩家外观编号位于本图继承模型与显式Bot模型之后。
