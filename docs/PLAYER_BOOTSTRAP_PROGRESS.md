# 玩家出生、时钟与装备同步

玩家使用服务端校验的账号配装、地图出生点和原生朝向。权威移动、武器与客户端预测已接入实际对局；实现范围见[移动](GAMEPLAY_INPUT_PROGRESS.md)、[背包](PLAYER_LOADOUT_PROGRESS.md)和[比赛流程](MATCH_FLOW_AND_SPAWNS.md)。

## 时钟与视角

CS6415 使用 `0 0 1 1`，由本版 `0x579f30` 按 `%i %i %g %g` 解析时间倍率。该字段必须显式初始化，正常倍率为 1；输入频率还受前台、帧频和调度影响。

服务端使用单调时钟和实际 usercmd 时间推进。合理领先的输入排队，过远或重复输入拒绝；commandTime 只确认已处理动作，不能随发送快照强行推进，否则客户端预测与渲染可能冻结。

PS+0x200 是旋转参考实体，普通身体视角使用 2047，不能默认指向本地实体0而重复叠加朝向。viewLocked／viewLinked 与远控相机链接分别处理，见[连杀运行时](KILLSTREAK_IMPLEMENTATION_LOG.md)。

## 输入 base 与装备

`0x5a18e0` 从 PS+0x340／+0x32c／+0x344 读取当前武器／offhand／alt，玩家标志和 ADS 也影响默认 usercmd。服务端保留已发送 PS 与输入 base，按客户端 message ACK 选择，可靠消息不更新该 base。

武器索引来自本图 NCS 和组合注册，不是 marketplace item ID。角色、默认六部件与玩家配件先在服务端校验，可靠发布并收到 ACK 后按准备／宽限／重生规则应用。注册历史在同账号连接间保持编号顺序，替代武器紧随父武器注册。

射击、普通／空仓换弹、ADS、切枪及飞扑使用真实组合 WeaponDef 的时长和弹药参数。装弹点只转移一次，重复输入／快照不重填初始弹药；动作恢复不能覆盖其它状态或复活后的新对象。
