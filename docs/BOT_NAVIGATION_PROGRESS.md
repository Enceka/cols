# Bot 跳跃、路线变化与脱困

2026-10-13。运行时继续使用 Rust 和本版 3.3.3.3 的运动／碰撞；初版代码检查使用独立 checkout 和构建目录，随后完成高楼及潜艇基地的原生客户端验收。

## AlphaBuild 对照

本地参考为 `../CODOL-AlphaBuild/CODOL_AlphaBuild_LAN 服务器端/CODOL_Server/dedicated/src/codol/player/`。`codol_bot.c` 的 `choose_goal` 随机挑选未被占用的远处节点，`try_mantle`／`mantle_drive` 把越障交给原生运动，普通跳跃保留500ms间隔；`stuck_escalate` 依次尝试侧移、重新寻路及重新选目标。`codol_bot_nav.c` 的 `CODOL_BotNavRouteFiltered` 仍用距离成本的 A*；其 negotiation 连接依赖已有原生翻越／梯子执行能力。

本轮采用随机目标、动作与路径协调、分级脱困的思路，额外加入路线区域偏好和近期行程避让。没有照搬 AlphaBuild 的跳跃高度、地址或无条件 negotiation 连接。

## 当前实现

- 地面图保留站立胶囊、18单位台阶、逐段地面支撑及有方向的落差连接。新增水平24..144、升高不超过39、降低不超过128单位的跳跃候选；墙体及低顶先作胶囊拒绝，再用真实 `Motion` 验证。
- 候选尝试0／50／100／150／200ms助跑，50ms一步、最多1200ms，必须真实起跳并落到目标支撑，水平误差不超过8、Z误差不超过1单位。原地起跳的低空中加速度不足以越过部分沟隙，不能假定已有跑速。
- 路径携带出发点、落地点和助跑时间。bot先接近出发点，再按当前武器和战术移动倍率重新验证；只有通过才执行原生跳跃按钮0x400。冲刺、ADS、寻路快捷转向及避让不会改写已验证的助跑／空中目标；出现敌人后仍完成落地。死亡、重生清理动作，重复tick不再次起跳。
- 每次规划从bot自己的随机序列取新种子。192×192×96区域成本增加0..80%的稳定偏好，避免逐节点随机抖动。最近32个实际行程点附近96单位再增加成本，降低反复走同一通道的倾向；所有成本仍不小于实际距离，保留A*距离启发式。固定验证种子可复现；零种子不会把随机序列卡死。
- 保留每个权威tick最多一只bot作图搜索的预算。2.5秒内移动不足24单位且确实有移动意图才算卡住；守射程不触发。先用新偏好重新寻路，再暂时放弃旧追击目标、重新漫游；恢复96单位进展后重新允许追击。语音和启动相关的同时工作不纳入本轮验证副本。

## 验证与边界

证据保存在 `research-output/bot-navigation-20261013/`。`highrise-jumps.json` 使用本图真实碰撞，7666节点、4390条跳跃边，12条由实际bot控制器完成落地。`maps-final-60.json` 是23张准备地图各60秒的后台对局验证，`native_client_used=false`；23图全部通过，21图累计303次真实起跳，总耗时52695ms；高楼11只bot达到移动门槛、17次跳跃、13次击杀、11次重生及19块玻璃破碎。具体逐图数据以报告为准。

回归覆盖跨沟、低台跳上、墙体／低顶／无落地面／过高／过远拒绝、动作保留、敌人出现、时钟回绕、重复tick、死亡／重生、区域路线可复现和两侧分流、近期路线避让，以及原有坡面／台阶／落差与玻璃交战。完整fmt／Clippy、476项Rust及102项Python通过，4项本地真实地图专项另外显式运行通过；结果见 `check-final.log`、`captured-maps.log` 和 `summary.json`。

这套跳跃能力由3.3.3.3的39单位普通跳跃驱动。高楼的 `jump_up_80`、原生翻越和梯子仍需独立运动及动画实现；不能把新增图边或后台对局通过称作124条原生negotiation动作全部接入。当前仍沿用已绑定的持枪移动动画，专用跳跃／落地动画、原生画面和长期稳定性需要后续复核。
