# 空投奖励共用流程

普通空投 2、多箱空投 9、空投哨戒 4 和空投 SAM 22 共用本版标记弹资源绑定、主武器投掷和飞行物理。运送、落箱、拾取、拾取奖励的 HUD 投影及原生验收尚未接通；四项不发布为可用奖励，不列为完成。

本版阿富汗注册标记弹为 293 `airdrop_marker_mp`、294 `airdrop_mega_marker_mp`、295 `airdrop_sam_marker_mp`、296 `airdrop_sentry_marker_mp`。它们均为 grenade 类型、class 6、offhand class 0，爆炸半径为 0。真实资源给出拉栓 600ms、投掷 360ms、出手延迟 129ms、速度 960、向上速度 120，以及 31 种材质的平行和垂直弹跳系数。资源中的 fuse 字段为 1000ms，但空投启动不以该字段作倒计时。

主武器标记使用拉栓、保持、松键投掷和出手延迟状态；出手只消费一个武器弹药并生成一次投掷请求。事件使用本版 `EV_PULLBACK_WEAPON` 35 和最后一发事件 37；offhand 武器状态及事件保持独立。换武器或死亡取消尚未出手的动作，保留其弹药；未确认可用处理器的奖励不因标记武器存在而自动发放。

Marker 飞行复用普通手雷的世界碰撞、继承速度、重力和捕获材质系数。按 AlphaBuild 的 `airdropDetonateOnStuck` 机制，在停止运动后产生一次落点信号；不制造半径伤害。30 秒仍未停止运动的对象只清理，不伪造落点。该清理期限是本地保护参数。本版 timed-detonation 标志消费者、原生投掷动画和落点仍需独立核对。

AlphaBuild `_airdrop` 的公共控制流程包括按奖励实例追踪标记、在出手时提交权限、按空投类型选择运输机与内容、物理落箱、持续使用拾取及归属处理。其权重来自 `scr_airdrop_*` 配置，不能将本版统计表第 23 列的分类值冒充随机概率。完整资源、源指纹和诊断数据保存在忽略目录。

回归覆盖四种注册武器绑定、拉栓保持、出手延迟、一次投掷、死亡/切枪取消、继承速度、停止运动落点和无半径伤害。`marker-real-map-check.log` 使用匹配本版阿富汗资源及碰撞，四种标记均在投掷后约720ms停止运动并产生一次落点信号；该测试只证明服务端物理，不代替原生动画或完整空投验收。
