# 本地房间与开局路由

原生自建房支持创建、浏览、加入、准备／取消、阵营与配装同步、地图选择、共同开局、结算返回和再次开局。房间名与成员属于已认证 title／UID／登录会话；房主名单决定冻结参与者，不能用客户端自报身份绕过准入。

描述最多 1024 字节，房间消息最多 16 KiB／64 条子消息，保留有界队列。推送以完整子消息分块，使用独立 S2C 加密序号，不消耗 RPC transaction ID。密钥留在私有服务状态，fixtures 使用合成值。

## Bot 与共享多人

`--native-bot-rooms` 提供单真人兼容房间；`--room-bot-fill 4..12` 为支持的自定义 TDM 房间设置总人数，真人加入时替换 Bot。两项互斥。Bot 由原生房主接纳并分队，使用 `Bot n` 昵称，没有账号或网络 socket。房间角色装配见[房间 Bot 展示](ROOM_BOT_AVATARS.md)。

共享房间只持有一份权威世界，各真人有独立输入、加密、ACK 和复制。公开浏览、真人可见、移动／交火、共同结算与再次开局已原生验收；模式和装备的完整对齐范围见[多人验收](MULTICLIENT_ACCEPTANCE.md)。

## 赛单、选图与剧情

赛单源文件保持 UTF-8，准备器生成 GBK wire 内容。`catinfo` 的页面值 0=PVE、1=PVP，presentation 值 2 为隐藏；`combattraining` 使用原生人机标志。最少／最多人数对应本版 dvar 1011／3265，不能套用旧版本编号。

自建房箭头只选择符合本版标志、容量和已准备资源的条目；黑房使用独立快速赛单，竞技场容量为 4。地图和模式入口见[选图](MAP_SELECTION_PROGRESS.md)、[入口规则](NATIVE_MAP_ENTRY_RULES.md)。

剧情首关使用独立资源采集分配，不依赖 TDM 世界。测试解锁、握手与初始化已有证据，任务、NPC 和通关玩法待接入，见[剧情](STORY_MODE_PREPARATION.md)。
