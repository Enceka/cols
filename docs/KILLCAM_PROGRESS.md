# 死亡与最终击杀回放

目标客户端3.3.3.3，2026-10-10。对照新版参考文档9.1、9.5、9.6；运行核心为纯Rust，未修改客户端程序。本文记录当前本地6v6玩家/Bot第一人称回放，不代表参考文档的全部演出已实现。

## 历史与生命周期

独立保存至多180帧、最近8秒的权威历史，不复用32帧网络ACK基线。历史包含角色位置/角度、武器/弹药/ADS/动作、生命/伤害、尸体、弹着、击杀栏及命中反馈。绝对时钟在展示时平移，剩余动作时长保持原值。

个人死亡先停留约1秒，再回放击杀前至多3秒和击杀后0.5秒。历史起点不能越过击杀者本次出生；不足500ms、缺少击杀者或采样间隙超过250ms时不伪造画面。回放期间实时模拟继续，玩家复活等待回放结束，同时保留原有3秒最短死亡期。

最终回放取真实最后一次击杀，结束后才显示原生结算。最终回放会替换个人回放，最终历史不可用时也取消旧个人回放。live→replay→live各有独立网络基线epoch，避免丢包/旧ACK把两个时间线拼接。死亡标识始终用实时队友列表清理，不让历史角色重新激活旧标识。

名片缓存位于0x37e8108，步长0xa8。切换被观察PS不会自动刷新它，因此每次回放进入时发送`L <killer> 7`，不能只修计分板或昵称configstring。昵称保持原生`Bot n`身份，背景、图标和称号沿用客户端资料/默认回退；尚未实现任意玩家自选名片的完整同步。

个人与最终回放共用倒计时截止时刻；退出回放后清空。历史命中材质仍在archival组PS+0x1ed0，倒计时在current组；两组在网络中的顺序与内存顺序相反。字体系数来自本版codec，未直接照抄2.6版本1.56的不可精确编码值。
