# 个人与最终击杀回放

单人 Bot 对局已实现权威记录、个人／最终第一人称回放、名片、倒计时、跳过和结算衔接。共享多人个人回放尚未完成等同验收，见[多人边界](MULTICLIENT_ACCEPTANCE.md)。

## 回放缓存与生命周期

独立保存至多180帧、最近8秒的权威历史，不复用32帧网络ACK基线。历史包含角色位置/角度、武器/弹药/ADS/动作、生命/伤害、尸体、弹着、击杀栏及命中反馈。绝对时钟在展示时平移，剩余动作时长保持原值。

个人死亡先停留约1秒，再回放击杀前至多3秒和击杀后0.5秒。历史起点不能越过击杀者本次出生；不足500ms、缺少击杀者或采样间隙超过250ms时不伪造画面。回放期间实时模拟继续，玩家复活等待回放结束，同时保留原有3秒最短死亡期。

最终回放取真实最后一次击杀，结束后才显示原生结算。最终回放会替换个人回放，最终历史不可用时也取消旧个人回放。live→replay→live各有独立网络基线epoch，避免丢包/旧ACK把两个时间线拼接。死亡标识始终用实时队友列表清理，不让历史角色重新激活旧标识。

| F跳过 | 实际usercmd从0x2000000变为0x2000008，检查0x08上升沿；最终回放不接受跳过 |

名片缓存位于0x37e8108，步长0xa8。切换被观察PS不会自动刷新它，因此每次回放进入时发送`L <killer> 7`，不能只修计分板或昵称configstring。昵称保持原生`Bot n`身份，背景、图标和称号沿用客户端资料/默认回退；自选名片的完整组合仍需单独验收。

个人与最终回放共用倒计时截止时刻；退出回放后清空。历史命中材质仍在archival组PS+0x1ed0，倒计时在current组；两组在网络中的顺序与内存顺序相反。字体系数来自本版codec，未直接照抄2.6版本1.56的不可精确编码值。

## 原生标题、提示和名片

最终回放提前发送 `s scr_gameended "1"`，显示本版“决胜杀”；新局清零。`ui_match_complete`／`ui_eog_show` 在回放和前三名结束后才打开，不提前跳到结算。

个人跳过提示使用 current HUD type1，本图 `PLATFORM_PRESS_TO_SKIP` 的本地化槽，经 CS952+slot 展开实际按键绑定。默认底部居中、y=-26、白色，最终回放不显示；退出时文字与计时一起清空。F 默认上升沿为 0x08，不能使用其它动作位代替。

名片从实际档案读取等级、转生、背景、图标和称号，经 clientState 与原生命令同步。前三名使用三个真实本局角色和持枪实体，见[前三名](TOP_PLAYERS_PROGRESS.md)与[持枪](HELD_WEAPONS_PROGRESS.md)。

## 验证边界

原生验证已覆盖个人自然结束和主动跳过、最终标题／无跳过提示、名片切换、100 生命重生以及回放→前三名→结算。协议回归覆盖字段编码、时钟重基、提示清理和可靠窗口重试。特殊载具／投射物镜头、完整庆祝演出及更多地图逐项画面／听感仍需复核。
