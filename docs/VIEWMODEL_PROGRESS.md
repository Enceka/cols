# 第一人称持枪模型与动画绑定

当前装配由本版武器默认部件、玩家配件、角色衣袖／手套及原生 DObj／XAnim 构成。切枪、换弹和稳定 ADS 已有实机证据；特殊武器及更多角色动作范围见[复核清单](REVIEW_PENDING.md)。

## 武器模型与部件

默认配方按武器及槽位关联，六个默认部件与玩家选择合并；同名默认件可以属于不同武器，不能选择首个同名 ID 或装入全部兼容配件。组合格式和注册顺序见[背包](PLAYER_LOADOUT_PROGRESS.md)。

DObj 模型、骨骼映射和 XAnim 活动节点由本版消费者和实际采集核对。更改 idle 编号不能替代修正资源绑定；模型名称存在、loaded 旗标、有效 DObj 与实际动作分别检查。手臂备用资源和完整角色组成也有不同路径。

## 原生角色组成

`0x51bc80` 读取 clientState+0x124 组成数量、+0x128 阵营、+0x12c 性别、+0x130 肤色。`0x40cbd0` 从打包字段按 11 个部件组读取一基索引，属于本版部件银行，不是市场 ID 或 NCS 模型 ID。

`0x40c980` 选择变体并写 clientInfo+0x39c..0x3b0；组成有效时，`0x5593e0 → 0x40c7a0` 从变体+12 取得最多两件第一人称模型，再装配枪械。单个 PS viewmodel 索引不能表达衣袖＋手套。

21 个打包字段保持实测 netfield 顺序；组宽度为 `[7,4,8,8,6,7,8,5,0,8,0]`。玩家及 Bot 都可使用角色组成，回放衣袖／手套跟随 donor，前三名副本保留明确第三人称外观，见[Bot 服装](BOT_OUTFITS_PROGRESS.md)。

## 诊断与验收

```sh
python3 tools/client_state.py --experiment EXPERIMENT_JSON --weapon-models
```

采集要求 connection_state=10，核对固定程序和实验归属，只读实际模型表、组合、骨骼和动画状态。角色792的实际衣袖、手套及 AK104 配件已读到；正常回放、复活和结算链路已验证。八种位池起点、非法索引、性别／阵营／肤色、角色包和包预算有回归；更多角色、特殊枪械和完整动作听感不由模型实读替代。
