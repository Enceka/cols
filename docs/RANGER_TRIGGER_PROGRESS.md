# Ranger两个扳机

- 持续扣住同一个扳机只发一次；换用另一扳机可发下一管。
- 同时输入时先走副扳机、再走普通开火路径，共消耗两发，各自生成一份真实射击/弹丸伤害；只有一发时仅生成一份。
