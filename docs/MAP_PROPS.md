# 地图油桶与可破坏车辆

纯Rust服务端从本版地图实体中发布真实 `script_model` 油桶和车辆，按原坐标、朝向及已注册模型绘制。准备器只接入 `explodable_barrel`／相应noteworthy与 `destructible_vehicle`，相同模型与点位的重复变体合并。不将其它剧情机关或静态装饰桶自动变成爆炸物。

当前正常地图目录中14图共140个物件已具备资源绑定：阿富汗、坠机之地、沼泽、交叉火力、庄园、贫民窟、荒漠边陲、核弹镇、航站楼、风暴、伏击、训练场、潜艇基地和高楼。每图采用自己的初始化NCS／CRC、真实地图实体和原生模型边界；仅共同构建／common校验一致时复用已核实的声音别名。未找到对应TDM物件或完整来源的地图不发布成功调用。其它剧情机关、玩具、电箱、分部件车门／轮胎及模型碎片未接入。

运行时为每个物件持有生命、燃烧、爆炸、残骸／消失状态与伤害归属。兼容规则为油桶150生命、受枪械／近战伤害后燃烧，每秒损失15生命，达到零爆炸；手雷波及油桶直接触发爆炸。车辆350生命，受伤冒烟，生命归零爆炸；存在已注册残骸模型时保留残骸，否则移除。新对局从完整状态开始，人物重生不会重置物件。

油桶爆炸半径250、中心伤害250、边缘1；车辆半径300、中心200、边缘75。这些是本地兼容行为取舍，不是恢复出的3.3.3.3官方服务端规则。爆炸采用世界遮挡、敌我政策、原拥有者和爆炸抗性，能伤害玩家并通过正常权威死亡结算记分和推进连杀。物件爆炸只有一次，连锁队列有界；自己的残骸不会挡住自己的爆炸，墙壁和其它物件仍可遮挡。

碰撞为原生XModel边界生成的旋转凸体，参与移动胶囊、射击、投射物和视线查询；不是原模型逐三角形／分部件物理。销毁后清掉油桶凸体，残骸按自己的模型边界更新。各连接只共享不可变地图资源，物件与玻璃销毁状态留在本次对局。

快照使用GENERAL实体256..383，模型、位置、三轴角度、残骸与移除状态跟随确认帧及回放历史。事件分配跳过该保留区。位置／角度的绝对基准不重置模型等普通字段；模型切换对已确认模型编号作XOR。资源文件通过 `props_file`绑定，校验客户端摘要、地图CRC、来源、数量与边界，声音通过原生动态槽480／481注册。

完整场景或回放切换可超过1154字节的净负载阈值。原生发送使用0x5a5490／0x5a5960对应的序号、分片索引、最后索引、步长和长度格式；先重组ACK及完整XOR／zlib负载，再推进同一个消息序号。队列发送完之前不发送更高序号的临时回复。普通小包保持原有编码。

阿富汗的原生验收通过Rust启动器完成：11个真实物件创建了原生DObj；正常射击触发油桶点燃、火焰、爆炸与消失，附近两个油桶连锁爆炸并造成一次真实玩家死亡。车辆正常扣血至零，客户端模型192切为191，实际画面保留损毁车体，爆炸使玩家生命降至4。原生FX环确认油桶和车辆特效，声音听感尚未逐项验收。其余13图资源绑定与23图后台运动／伤害／重生验证通过，不扩大为逐物件原生验收。

源码与合成回归可提交；完整捕获、物件表、模型边界、配置、声音样本及截图均在忽略目录 原生状态采样。`barrel-result.json`、`vehicle-result.json`、`map-coverage.json`与 `maps-with-props-60s.json`保留对应证据。
