## 进度、库存与归属

普通三项以最高选中门槛为循环长度。3／4／5在第3／4／5杀发放，第6杀进入新轮，第8／9／10杀再次达到门槛；调用不重置进度。同种奖励最多保留一份，达到门槛时已有库存就跳过，之后消费不补发该轮。死亡保留已赚库存，换预览也不回填已跳过奖励。

库存使用稳定实例与预留／消费票据。效果保留原操控者和原始生命归属，不能把旧生命弹体或连锁击杀算进新生命。普通奖励进度、固定25杀核弹和战绩分开；奖励直接及连锁击杀计分，但不推进奖励或核弹。零起始两轮与技能击杀排除已有原生验证，连锁来源有权威回归。
