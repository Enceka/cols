## 2026-10-15：显式父动画权重修复，攻击机旋翼实机通过

只读活动动画树采样定位到叶节点11虽然已有目标权重1，但父节点10权重与速率均为0，叶节点时间因此不推进。opcode2调用的0x64bed0负责混合兄弟节点，并不会启用父节点；此前“启用父权重”的解释作废。现在从本版XAnimEntry捕获父索引，资源准备保留parent10，快照同一时刻先发送父10、再发送叶11的权重1/速率1目标，保持无重启、无通知。
