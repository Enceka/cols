精确空袭6、隐形轰炸11及迫击炮17已接入普通规则。本图真实选择器注册保存在正常资源表，仍按匹配地图与CRC加载；资源不足时不生成可用动作。

- 迫击炮三次有效确认后消费一份库存，六枚独立弹体使用1600..1605，原生DObj、真实地形碰撞与落地FX均已确认。

- EV_PLAY_FX补上本版原生消费者要求的方向字段；地面FX源略高于碰撞面。
- 复活卡住已定位到第一人称自身持枪实体27的延迟链自循环。快照按当前视角排除自身外部持枪实体，保留其他角色、尸体与领奖台的武器；两种空袭近距离本人死亡后的复活、客户端时间推进及剩余奖励调用均重新通过验收。
- 延迟攻击保留原始生命归属，旧生命攻击可计分，但不推进复活后的连杀进度。

实机使用隔离账号、普通窗口键鼠及只读采样，未修改客户端EXE/DLL。种子8加一次真实击杀只用于缩短效果验收；零起始累计门槛的证据独立记录，不能混称。
