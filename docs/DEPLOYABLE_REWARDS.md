# 连杀奖励部署设备

本版3.3.3.3的哨戒奖励16已具备服务端部署、自动判伤、击杀归属和生命周期，阿富汗原生客户端已确认模型与实际击杀。完整原生炮塔动作、枪口特效、持续开火声音和拾取搬运尚未完成，不能将该条目列为完整验收通过。防空炮塔和空投哨戒仍需各自的防空与空投流程。

## 资源与调用

`prepare_reward_resources.py`只使用初始化地图的匹配NCS、客户端SHA和只读资源捕获。模型保存真实边界；伴随武器保存六档伤害和距离。退化或超出部署几何预算的模型不生成可部署边界，不用默认尺寸补齐。奖励16仅在模型、残骸、爆炸特效、武器伤害和射速全部有效时发放可用库存。

阿富汗绑定为激活武器327、模型125 `sentry_minigun`、残骸126、伴随武器347 `sentry_minigun_mp`及爆炸特效78。该武器资源的射速为50ms、有效伤害档为1200/1800单位处20点。模型选择、1800单位目标范围和射击扇区是本服务端的兼容实现，不声称恢复了本版官方GSC规则。Pro物品仍保持独立身份。

普通奖励门槛排序、权威死亡去重、库存、死亡保留和新生命门槛共用连杀状态。按对应原生动作槽选择奖励，装备抬起完成后在面前96单位尝试部署；成功才消费库存并返回原枪。失败返回原枪并保留库存。原生接受位置提示、预览摆放、取消和拾取搬运仍需完整接入。

## 世界和判伤

设备占用实体384..447，地图可破坏物占256..383。碰撞按各自范围更新；油桶、汽车和设备的刷新不会清除另一组形状。设备快照和事件进入ACK历史及回放。

部署检查真实模型边界、四角地面、坡度、地面高度差、世界净空、视线和存活人物占位。四角最大高度差8单位、1000点设备生命、60秒期限、500ms首次射击延迟、前方左右70度扇区和5秒残骸保留均为明确的本地兼容数值。

设备从敌方存活目标中选择最近的可见目标，冷血技能 `modNoSentryGuns` 阻止锁定。全局EMP暂停射击。射线仅排除设备自身碰撞，其它设备、地图物体、墙壁和友军仍会挡弹。伤害走现有权威死亡、记分、击杀栏和连杀归属路径；持有者死亡不会移除已部署设备。友军不受设备伤害，也不能伤害友方设备。

玩家和Bot枪弹、近战、手雷及地图物体范围爆炸统一分发设备受损。生命清零只产生一次爆炸特效，切换真实残骸及残骸碰撞；到期和对局结束移除设备并释放碰撞。

## 原生状态与验证边界

当前实际设备使用GENERAL模型路径。ES+0xd0提供注册武器，+0xac及四个事件槽传输真实 `EV_FIRE_SENTRY70`，事件参数宽度为0。发送保持完整/增量基线，支持计数器回绕与残骸武器清零。TURRET11共享GENERAL字段表的事实和编码有独立校验，原生DObj构造仍缺少必要状态，实际设备不启用该类型。

只读资源捕获已确认模型拥有 `tag_aim_pivot`、`tag_aim`、`j_spin` 和 `tag_flash`。伴随武器单发声音为空，持续开火和冷却别名分别为 `sentry_minigun_fire`、`sentry_minigun_cooldown`。这些资源事实不等于声音或动作已经播放。

隔离实机证据位于 `research-output/all-killstreaks-20261014`，完整资源和账号不进入提交：

- `sentry-earned-frames.json`及对应服务日志记录零起始5次权威死亡达标和原生可用动作槽。`sentry-first-result.json`记录场地不适合时库存未消费。
- `sentry-native-effect-result.json`确认实体384、模型125、非零原生DObj、库存消费及自动击杀。效果验证使用显式种子4加1次真实击杀，不作为零起始门槛证据。对应服务日志记录74次武器347的设备击杀及调用方归属。
- `sentry-native-events-result.json`确认注册武器347和123种原生事件计数值。该采样未捕获枪口特效或设备开火声音，不能作为这些表现的通过证据。
- `sentry-placement-grid.json`以本版真实碰撞检查可部署地点。资源诊断不替代原生验收。

合成回归覆盖资源缺失、无地面、墙体、人物占位、调用失败保留库存、友军挡弹、射速及伤害、遮挡、冷血技能、EMP、范围伤害、重复毁坏、残骸到期、持有者死亡后归属，以及原生字段独立解码。共享工作区中的其它服务改动独立于该验证；连杀验证使用提交基线加本项改动的隔离构建。
