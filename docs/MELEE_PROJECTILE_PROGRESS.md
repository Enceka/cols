# 近战与投射物接续

2026-10-11。运行核心仍为纯Rust，研究对象为未修改的3.3.3.3客户端。

## 先分清原生类型与武器类别

本版枚举名字表`0xce3f78`依次为bullet、grenade、projectile、riotshield、bomb、melee。WeaponDef+0x47c使用该类型，+0x480是步枪/手枪等类别，二者不能互换。本版`0x55e45f`也明确以`type==0`进入子弹表现路径。

现有代码只排除发射器等类别，会让“步枪类”的弩和“手枪类”的弹道刀进入子弹属性解析。已改为只有原生bullet类型可建立即时命中伤害，同时保留原有特殊类别/标记限制。

必须区分实际行为与缺陷触发条件：实采`crossbow_mp`、`crossbowrare_mp`、`knifeballistic_mp`均为type2，原始近段射程均999999；旧代码还会被通用子弹射程上限拒绝，因此**没有证实这三把原始武器在实机造成了错误即时命中**。本次修复让排除规则基于真实类型，不依赖这个射程值。回归将投射物射程改为1000的诊断变体，旧实现确实会产生子弹伤害请求，新实现仍拒绝该请求；普通步枪/手枪继续产生射击请求并正常扣弹。

`projectile-classification-before-valid.log`保留旧实现的失败；首次合成夹具缺少有效近段射程的失败另存`projectile-classification-before.log`。`projectile-type-captured.log`验证三种实际定义和合法射程诊断变体。完整飞行实体、撞击、爆炸和范围伤害仍未实现，本项不把“没有错误子弹伤害”称作投射物可玩。

`projectile-type-check.log`完整341 Rust、50 Python、fmt/Clippy通过，优化构建完成。实际射程诊断只在测试内复制定义，未修改资源文件或玩家账户。

## 已确认的近战入口，尚未接入战斗

实际资源中非零开火延迟主要来自10种近战武器和盾牌。它们还涉及独立状态、无弹匣、体力和冲刺攻击，不能仅删除延迟/弹药校验。

- 原生按钮0x4为近战，`0x426de0/0x427000`检查上升沿和武器状态；UserCommand已解码melee yaw/distance/entity。此目标编号来自客户端预测，后续必须重新验证距离、视线和真实受害者，不能直接当作伤害结论。
- `0x426620`创建state13；普通持枪近战读总时长+0x714、伤害延迟+0x6f4，冲刺分支读+0x718/+0x6f8。独立近战武器另读+0xd10/+0x6f0及体力路径。
- 当前M4/AK104普通近战为699ms/250ms，USP为500ms/50ms；+0x6e0伤害均135。刀具数据另有135/150等值，不统一替换成枪械伤害。
- 本版事件53=EV_MELEE_SWIPE、54=EV_FIRE_MELEE、55=EV_MELEE_INIT、62=EV_MELEE_END；`0x425f00`进入state14并发伤害时机事件，`0x425c50`按武器进入state15及收回动作，分发器`0x428df0`处理对应阶段。
- `0x41c9a0`把预测近战接近目标写入PS+0x4a8/+0x4ac，并受站姿/移动条件约束。范围、接近移动和刀具体力尚需继续核对，当前没有接入一个仅有挥刀动画的伪实现。

源证据保留在忽略目录`native-melee-complete.c`、`native-melee-dispatch.c`、`native-melee-target.c`及原始WeaponDef。最初Containing导出落在函数中段，未作为完整调用约定依据；后续从实际函数边界重新导出。

## 已接通：TDM普通持枪近战

普通枪械现支持近战按钮上升沿触发挥击，按本枪的持续时间、伤害延迟、收回时间和近战伤害推进13→14→15→0。判伤只触发一次，长按不会连续挥击，重复输入时间不会重放；挥击打断未完成的换弹/点射，不转移换弹弹药，也不消耗子弹。抬枪、切枪和菜单期间的近战按下不排队。独立刀具、盾牌和冲刺接近暂未开放。

当前伤害范围为保守的64单位正前方检测，取本版普通/冲刺分界，不宣称已恢复完整原生宽度和吸附判定。服务端使用命中时的真实位置、视角、当前存活目标和地图遮挡；不信任客户端上报的melee entity。队友挡住挥击且不受伤，墙后/范围外/已死亡目标不受伤。出生保护及早于当前生命的迟到命令均拒绝；后一项同时补上原伤害路径的时间回绕边界。

有效击杀沿用正常死亡、尸体、计分、名片和历史回放链，但不计爆头、不产生弹孔。击杀栏发送原生MOD8（908）刀杀标识，实际持枪编号仍保留用于回放。旧训练靶诊断未接此伤害路径，因此该模式保持关闭，避免只有动作没有伤害。
