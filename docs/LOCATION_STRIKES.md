# 选点连杀与轰炸

3.3.3.3 的精确空袭6、隐形轰炸11和迫击炮17共用 Rust 选点、库存票据和攻击调度器。鹞式7仍需悬停攻击控制器，暂不开放。

选点协议与旧版本不同：PS+0x234为字段143/8位。低两位选择CS2047+shader，接着五位给出显示大小，最高位选择方向。目标客户端的XY指令字节在量化后加128并回绕；原生地图中心发送0，不能直接按0/255解释。方向字节不带该偏置。独立证据见 `fixtures/protocol/location-selection-3.3.3.3.json`。

确认0x20000、取消0x40000按已执行指令的上升沿处理。取消、切枪、死亡、EMP和比赛结束撤销预留而保留库存。迫击炮收齐三个有效地面点后才消费一份库存；计划失败或容量不足也保留库存。

空袭黄圈、炸点与判伤共用量化后的世界半径。原生绘图消费的是地图高度乘以五位大小，作为选择器的完整宽度；服务端把一半宽度作为范围边界。精确空袭的目标半径1100、隐形轰炸2600及迫击炮选择器800为明确的本地兼容参数，随本图五位量化落到实际值。轰炸炸点与单次爆炸半径均限制在空袭选区内，范围外角色不因这次轰炸受伤。此调整使本地玩法的黄圈与危险范围一致；Alpha脚本原先的长条轰炸路径不被当作圆形范围继续使用。

精确空袭保留三架飞机、每次十二个落点、2秒分批及方向选择；隐形轰炸按200单位间距和径向散布，在选区内保留落点。飞机模型147/140及高度来自本图捕获，地图外部分路线不发送越过16位坐标的实体。迫击炮保留三组、每组两弹、2.5秒分组、1.3秒组内间隔，以及75度/6000单位/飞行30%开始的参考弹道。800重力及上述时序为本地适配参数，实际弹体逐20毫秒扫掠本图碰撞。

`artillery_mp`和`stealth_bomb_mp`的本版武器定义不含半径伤害，空袭分别采用Alpha脚本的512/200/30和896/300/50。迫击炮使用本版333武器的512/600/75。角色判伤保留脚本的室内距离优势及队伍过滤，也允许奖励伤害操控者本人。自杀不增加击杀数。已死亡旧生命发出的攻击仍能计分，但不能推进复活后的连杀进度。

爆炸使用本图实际注册的 `explosions/artilleryexp_dirt_brown`（67）。EV_PLAY_FX100的本版消费函数0x50dc40还要求ES+0x3c朝向，事件现在独立发送FX编号和沿地面法线的角度。特效源略高于碰撞面，避免量化到地面内。迫击炮弹体使用1600..1648，SAM使用1648..1664；事件分配器跳过整个导弹区间，保留1668..1700声音实体。

隔离验收中的起始种子用于缩短效果验证，不能代替零起始门槛证据。种子测试同时设置延后的Bot开火时间，解除旧测试参数的操控者伤害屏蔽。两种空袭的模型147/140、实际爆炸FX、操控者生命下降到0以及复活恢复均已确认；迫击炮1600..1605六枚独立原生弹体DObj及落地FX已确认。正常资源表已发布6/11/17选择器能力。

原生复活曾使第一人称自身的外部持枪实体27在延迟处理链中出现自循环，0x504fa0无法退出。快照现在按当前视角排除该玩家的外部持枪实体，保留其他玩家、尸体和领奖台持枪模型。修复后两种空袭近距离本人死亡、复活和剩余奖励调用均确认无循环。

证据位于忽略目录 `research-output/killstreak-controls-20261014`。仓库回归覆盖显示大小量化、范围外免伤、三次确认去重、取消重试、真实地面碰撞、室内优势、操控者受伤/自杀、旧生命奖励计分和进度分离、生命周期及实体编号隔离；完整工作区检查和真实地图回归通过。
