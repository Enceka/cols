# 通用武器配件与移动

武器及配件身份来自本版只读arsenal和独立商城表。数值合成器恢复字段排序、原始单位、覆盖／增量／原值比例／乘法及ADS速率派生；未解析的资源指针不能覆盖已消费的玩法字段。正式背包按所有权与部位冲突验证选件，不能使用紧凑索引产生的商城别名。

机械瞄具存在且没有外加镜时，组合名按原生0x568c80追加兼容的`sco_none`。物品20008是默认装配，不是需要所有权的升级件；已选外加镜继续使用其自己的配置。这个默认项携带原生瞄具显隐标签，不能仅因名称为“none”而删除。瞄具／准星父项的更多组合仍需按3.3.3.3的实际消费者恢复，2.6.9.7参考文档的偏移不能直接套用。

AK117熔岩的原配件10547／10531／10545已通过修复后的原生ADS画面对照：隐藏黑色后部结构，顶部自带瞄具准星对齐中心，枪体上缘位于瞄具下方。组合及原生动作实读、完整开镜帧和一张截图见`lava-ads-after-reboot/acceptance-proof.json`；该样本不代表全部枪械／瞄具组合已验收。

当前服务器消费合成后的弹药容量、射击／换弹／切枪／ADS／拉栓时间、伤害／衰减／部位倍率、弹丸数、散布、近战和冲刺参数。普通移动读取WeaponDef+0x7c8，开镜移动读取+0x7cc。原生PM_CmdScale0x416aa0先应用0.4基础开镜系数，再选择开镜倍率替换普通倍率；玩家、Bot及切枪后的状态都保留各自的两个倍率。源码证据为`weapon-mobility-analysis/pm-cmdscale.c`及原始指令对照。

M4枪托22142／cqc_stalkerm4的实际属性为kind7、op7、offset0x7cc、operand1.2；AFG握把20743／for_gripafgm4在同字段加0.1。普通倍率0.95不变，开镜倍率由1.0变为2.2／2.3。AFG的13750等紧凑索引别名不属于该商城部件，装备验证会拒绝。

`stock-native-acceptance`在独立服务资料的原生训练场景中使用普通W＋右键输入，每次2.5秒；未改客户端、武器资源或正常账户，未截图。汇总及恢复引用见`stock-native-acceptance/live-proof.json`。三个独立客户端均实读对应开镜倍率、持续30发弹匣和双方武器编号352。通过匹配相同commandTime／spawnCount，对照原生预测与收到的服务器PS：
