# 原生武器行为

目标为未修改的3.3.3.3客户端。持枪、弹药、切枪、换弹、ADS、散布、近战、点射和拉栓由服务器状态机与原生快照字段同步；实际武器和配件参数来自本版只读资源采集。原生商城表独立验证物品身份，紧凑索引中的别名不能作为可装备物品。普通第三人称、尸体、回放和前三名持枪见`HELD_WEAPONS_PROGRESS.md`，Bot单发狙击动作见`BOT_SNIPER_PROGRESS.md`。

## 电鳗与默认瞄具

电鳗为物品11857／`famasss_mp`，原生fire_type4、四发点射、35ms间隔、36发弹匣。准备验证接受1～2000ms的非零间隔；零间隔仍拒绝。真实背包11751／11758／11762已通过资源集成，原生采样确认36→32及换弹32→36，见`eel-lava-native/eel-fire.json`和`eel-reload.json`。这组证据不将电鳗作为自动枪或充能枪。

原生装配器0x568c80在已选机械瞄具kind10、没有外加瞄准镜kind3时，将`sco_none`追加到组合名末尾。服务器按本枪兼容表和独立商城身份解析物品20008的原生编号，作为内部默认装配使用；不要求持有额外升级物品，也不覆盖已经选择的外加镜。其kind39属性控制`tag_down tag_frontsight_down`的隐藏，保留原生瞄具、模型和ADS动作。外加镜沿用各自的ADS动作及瞄具标签。

AK117熔岩为物品10609／`ak104ss_mp`，当前真实配件10547／10531／10545与默认机械瞄具的组合补齐12218／`sco_none`。可选10608／`the_fixsmallak104ss`使用热成像ADS动作，不能当作自带瞄具强制装备。顶部自带瞄具的视线与枪体遮挡仍需对照用户提供的原生参考图验收；已有训练及团队竞技样本的完整ADS状态、模型和弹药验证不代替修复后的画面对照。

真实目录审计覆盖166条子弹武器身份，165条通过背包装配和准备验证；`minigungunship_mp`的fire_type6仍明确拒绝，等待原生旋转／预热状态机。目录审计见`eel-lava-native/gun-audit.json`，不代表166把枪全部经过原生视觉、听感和射击验收。

## 自由与命运

已捕获自由csg12ss／blk／cny及命运g36css／blk／cny六组原生替代定义。第二形态没有独立商城物品，所有权来自原武器；合成自己的射击、ADS、伤害、散布与动作参数，配件由原武器的合法装配传递，并按替代定义的属性表重新合成。两形态共享原生弹匣和备弹键，切换不补弹。

原生变形使用drop state5／animation19、raise state2／animation20及WeaponDef+0x754／+0xd28。PS+0x344和输入槽依次为primary、paired presentation、offhand。两形态都登记到原生PS武器数组；主形态与副武器保持原有席位，替代形态使用额外席位4／5。0x410300直接查找当前形态，单独发送paired编号不能代替当前形态的数组登记。服务器拒绝缺少当前形态、重复替代编号或无效编号的快照，不新增库存物品。

`special-weapons-native-fixed/live-proof.json`记录基础自由／命运的原生切入、切回、共享弹匣、换弹和开镜；预测与服务端最终编号／弹药一致。自由狙击形态持枪画面已定向确认，原生phase6／7、6→5扣弹和5→6换弹已采样；命运主／副形态30→20→10、换弹恢复30及返回主形态已采样。自由还完成手枪切出／返回。六种变体及真实M4配件组合的资源集成检查见`weapon-mobility-analysis/captured-integration-final.log`，颜色变体不宣称各自完整视觉验收。

自由主形态一次采样曾出现一帧预测clip4／fire_count2，最终预测与服务弹匣均5；证据保留，不能将单次稳定结果当作整个预测路径完全验收。重复PS读取及原生定义实读确认fire_type1；新采样220组同命令的弹药与位置均一致、fire_count只见0／1，但采样后段出现额外攻击输入，不能当作严格单次按下的完全复核，原异常仍保留。声音、完整变形／射击／换弹动作及更多回放组合见`REVIEW_PENDING.md`。

## 通用配件效果

数值合成器恢复0x42ba70收集、0x42ba40排序、0x42b380字段派发、0x42b270／0x42b300计算及0x42af20 ADS速率派生。服务器使用合成后的弹匣容量、备弹、射击／换弹／切枪／ADS／拉栓／近战时间、伤害及距离衰减、部位倍率、弹丸数、动态散布、普通／开镜移动和冲刺参数。客户端通过同一个原生合成名称装配模型、瞄具、动作及已有音效／后坐力消费者；未恢复的参数不能仅因已合成就标为玩法生效。

PM_CmdScale0x416c16..0x416cc4在开镜移动时选WeaponDef+0x7cc，替换普通移动+0x7c8，再乘独立原生0.4系数及角色／状态倍率。玩家、Bot和切枪后的状态均使用各自武器倍率，配件不再被固定普通倍率抵消。M4枪托22142／cqc_stalkerm4将开镜倍率1.0加至2.2，AFG握把20743再加0.1至2.3；普通倍率仍0.95。无技能且平地的参考速度分别76／167.2／174.8单位每秒，来自实际记录而非自定百分比。详情及原生验收见`WEAPON_ATTACHMENTS.md`。

M200快瞄握把22208按实际kind9／op8使400ms ADS变352ms，并重新计算速率；Ranger副扳机及2／3／4发点射见`RANGER_TRIGGER_PROGRESS.md`和`BURST_FIRE_PROGRESS.md`。散布更新PS+0x350及实际站／蹲／趴、移动、转向、开火和ADS参数；弹丸逐个计算真实距离／部位伤害，随机种子仍是本项目实现。

## 明确边界

独立两手弹匣、独立弹匣的替代模式、延迟／充能开火、完整枪械穿透、弩／弹道刀等投射物仍有未接入路径。未恢复的投射物不会进入即时子弹判伤；不能以其它枪的数据替代。完整武器听感、第三人称动作和回放组合独立复核。地图、房间、结算、导航和角色的现状见`REFERENCE_ALIGNMENT.md`及各专题文档。
