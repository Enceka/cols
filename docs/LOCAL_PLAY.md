# 本地正常游玩

本版为3.3.3.3客户端、GameHub Wine和纯Rust服务端。使用已标记的客户端及原有本地账号。本机只保留`server/client-work/CODOL`一份实际客户端，工作区的`CODOL`是指向它的符号链接；Wine环境与服务资料独立保存。

在`server/`运行：

```sh
python3 tools/play.py
```

脚本构建优化版服务端，然后运行到用户退出游戏或终端收到Ctrl-C。结束时停止本次服务、恢复研究副本的临时证书，保留账号、背包和设置。可以用`--seconds 300`进行有界验证；`tools/gamehub_run.py`原诊断模式继续保持时限及采集预算。

原生入口：玩 → 多人竞技 → 创建房间 → 战术团队竞技。进入房间后用地图预览箭头选已准备地图，再点准备。11个Bot自动加入。原生创建列表没有独立的combat条目，快速人机入口仍走赛单。

当前本机准备目录：

- `research-output/native-tdm-map-catalog.json`：22张独立地图准备，包括Afghan、杀戮小屋/安全屋、坠机之地、Bog、交叉火力、庄园、贫民窟、山景别墅、杂草丛生、锈迹之地、核弹镇、货轮、航站楼、暴风雨、伏击、靶场、废弃都市、滨海镇、潜艇基地、高楼及两个黑房。黑房通过“黑房人机”快速赛单进入，原生自建房禁止选择这两图。
- `research-output/tdm-afghan-hud-state.json`：快速人机入口的默认准备。
- `client-work/wine10-throwables-20261011`：已有对局验收证据的游戏环境，目前存在Wine server失联，不能直接视为可正常启动；当前恢复状态见[客户端启动](CLIENT_STARTUP_RECOVERY.md)。

可分别用`--map-catalog`、`--game-state`、`--prefix-name`指定替代路径。这些准备含本机实际资源引用，不是可直接带到其它机器的便携包。缺失时需先按本版资源采集/准备流程生成，不能复制其它地图CRC。

同一客户端目录只允许一个受管运行会话，所有Wine环境共用其独占锁。第二次启动在修改配置、临时证书和启动本地服务前退出，并报告占用的harness或项目进程；不会替使用者关闭现有会话。正常退出与SIGTERM清理期间持续持锁，操作系统在进程退出时释放锁，残留锁文件不代表仍有会话。

正常配置为7500分（每击杀100分）、10分钟，双方各6人。带`end-test`的准备文件是快速结算测试，不能当成正常对局配置。

批量验收使用`codol-server verify-maps`及独立诊断catalog：后台批量检查已覆盖22张正常图；26张图的配置队列可一次生成，随后自动准备资源、筛选碰撞有效的原始出生点、后台检查、原生短局和失败诊断，并恢复指定的正常客户端。`--native-new-only`仅验本批新图；旧缓存仅在缺少世界碰撞证明时补采碰撞；高楼／潜艇基地的缺失材质可通过受限原生初始化请求补采。正常账号／配置不参与诊断写入。命令、覆盖范围和证据见[地图快速验收](FAST_MAP_ACCEPTANCE.md)。

正常游玩模式取消harness一小时、大厅1024帧和游戏快照帧数导致的主动结束；新连接仍验证票据和MAC，活动连接在每个通过MAC/序号校验的业务帧后续期本地房间与UDP对局租约（不复活过期或已撤销的连接）。达到采集预算后停止写逐包文件，继续处理游戏协议；单个运行日志达到64MiB后清空重写。它不保证操作系统、Wine或资源故障下永不退出。

STUN地址发现服务也已取消“记录满512个包就不再响应”的旧限制。采集仍最多512次尝试、队列最多8条；应答与磁盘记录分离，队列满或写入失败时丢弃诊断记录并继续响应。关停最多等1秒收尾后取消剩余记录，不让慢磁盘卡住退出。此处记录为有界尽力采集，不能再将目录文件数当作收到请求总数。

实机验证及尚未完成的功能见`REFERENCE_ALIGNMENT.md`与`MAP_SELECTION_PROGRESS.md`。当前仍在对齐更多地图、武器、回放、装备及启动器功能，不能称作参考文档的完整移植。

macOS自动测试窗口工具由`sh tools/build_game_window.sh`构建。所有输入先校验实验PID及研究副本标记，再确认游戏为前台；Wine无应用包时，AppKit激活失败可通过macOS公共进程API恢复窗口焦点。桥接程序只接受带研究标记的本版游戏进程，不读取或修改游戏内存；焦点复核失败仍中止输入。

已准备地图现含`feedback_resources`：由本图NCS导出普通/致命命中材质和命中声槽，分别显示白色/红色并按1000/600ms淡出。旧准备文件需用相应捕获重新生成此项；不要把另一图的CRC或资源槽直接复制进去。

已准备地图现含`replay_resources`：从本图NCS本地化银行生成个人回放跳过提示，按当前客户端按键绑定显示。最终回放使用原生“决胜杀”标题，无跳过提示；回放结束后依次展示前三名和结算。

已准备地图支持原生队友死亡骷髅定位：只显示同队队友，重生或到期清理，视野外不显示边缘箭头。由本图`feedback_resources.death_material`绑定，缺失时关闭。
