# 本地正常游玩

本版为3.3.3.3客户端、GameHub Wine和纯Rust服务端。使用已标记的研究副本及原有本地账号。

在`server/`运行：

```sh
python3 tools/play.py
```

脚本构建优化版服务端，然后运行到用户退出游戏或终端收到Ctrl-C。结束时停止本次服务、恢复研究副本的临时证书，保留账号、背包和设置。可以用`--seconds 300`进行有界验证；`tools/gamehub_run.py`原诊断模式继续保持时限及采集预算。

原生入口：玩 → 多人竞技 → 创建房间 → 战术团队竞技。进入房间后用地图预览箭头选已准备地图，再点准备。11个Bot自动加入。原生创建列表没有独立的combat条目，快速人机入口仍走赛单。

当前本机准备目录：

- `research-output/native-three-map-catalog.json`：Afghan、杀戮小屋/安全屋、坠机之地的独立地图准备。
- `research-output/tdm-afghan-hud-state.json`：快速人机入口的默认准备。
- `client-work/wine10-minimap-20261010`：已验证的游戏环境。

可分别用`--map-catalog`、`--game-state`、`--prefix-name`指定替代路径。这些准备含本机实际资源引用，不是可直接带到其它机器的便携包。缺失时需先按本版资源采集/准备流程生成，不能复制其它地图CRC。

正常配置为7500分（每击杀100分）、10分钟，双方各6人。带`end-test`的准备文件是快速结算测试，不能当成正常对局配置。

正常游玩模式取消harness一小时、大厅1024帧和游戏快照帧数导致的主动结束；新连接仍验证票据和MAC，活动连接在每个通过MAC/序号校验的业务帧后续期本地房间与UDP对局租约（不复活过期或已撤销的连接）。达到采集预算后停止写逐包文件，继续处理游戏协议；单个运行日志达到64MiB后清空重写。它不保证操作系统、Wine或资源故障下永不退出。

实机验证及尚未完成的功能见`REFERENCE_ALIGNMENT.md`与`MAP_SELECTION_PROGRESS.md`。当前仍在对齐更多地图、武器、回放、装备及启动器功能，不能称作参考文档的完整移植。

三图准备现含`feedback_resources`：由本图NCS导出普通/致命命中材质和命中声槽，分别显示白色/红色并按1000/600ms淡出。旧准备文件需用相应捕获重新生成此项；不要把另一图的CRC或资源槽直接复制进去。

三图准备现含`replay_resources`：从本图NCS本地化银行生成个人回放跳过提示，按当前客户端按键绑定显示。最终回放使用原生“决胜杀”标题，无跳过提示；回放结束后依次展示前三名和结算。

三图现支持原生队友死亡骷髅定位：只显示同队队友，重生或到期清理，视野外不显示边缘箭头。由本图`feedback_resources.death_material`绑定，缺失时关闭。
