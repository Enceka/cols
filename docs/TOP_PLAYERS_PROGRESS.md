# 前三名展示与结算名片

未修改的3.3.3.3客户端、纯Rust服务端。最终回放后使用本局真实得分、角色、持枪和名片展示前三名，再进入12人比分结算并返回房间。

## 展示与退出

顺序为：最终回放退出→展示场景快照被ACK→打开原生前三名界面→从打开命令ACK开始展示6秒→关闭命令被ACK→比分界面→返回房间。每局独立维护状态，重复处理不重开界面或重复入场。

按得分降序、击杀降序、死亡升序、client编号升序选择前三名。`sf_top3players`来自本图NCS category8（base4291、64槽、零基），通过`q <slot>`打开、`u <slot>`关闭；当前三图独立采集为slot16，未准备资源不猜槽位。

三个人物使用本局角色部件、武器和本图站立动作，使用原生CORPSE渲染路径的姿态实体19..21，donor指向真实参赛者，explicit idle动画使其站立。客户端名单始终只有原始12人；原始角色隐藏，其身份保留供名片读取。站位从本图出生区域选择，以站立胶囊落地，并检查摄像机到脚／躯干／头部的视线。展示帧使用独立基线并清除战场尸体、弹着、击杀栏和命中HUD。

姿态实体不创建新的clientInfo记录，原生记分板和结果缓存始终只有12位真实参赛者。0x57b760／0x5788f0会将有效clientInfo复制到结果界面缓存；额外的展示client会进入结果缓存并触发缺失身份的玩家资料回退，因此展示只复用donor外观。姿态在首个展示快照就下发，武器链接跟随下一帧；保持到比分界面和地图退出，不提前删除人物。完整帧记录这些实体的实际标量基线，后续增量按同一基线编码。使用0x80000初始化新的donor动画树；复用现有尸体槽时推进generation并翻转原生重置位，再按显式站立动作播放，避免继承旧死亡树。

固定摄像机使用PM_INTERMISSION6和otherFlags0x800；`0x4522b0`跳过玩家输入预测，服务端固定输出位置和角度。进入比分时继续保留固定镜头。普通观战名片在展示期间通过`ui_hide_playercards=1`隐藏，每局初始化恢复0，独立前三名名片不受它控制。

原生独立挂枪实体覆盖Bot、尸体、回放及展示人物；三人的枪械模型与排名界面已有同帧视觉证据。当前演出为持枪站立，官方完整入场／庆祝动作和专用展示场景仍未恢复。细节见 `HELD_WEAPONS_PROGRESS.md`。

## 名片资料

等级／转生来自校验CRC、投影和归属后的服务端private档案：含CRC快照rank位于4887、prestige位于4883；rankVersion4891不是转生。等级1..70编码为clientState的0..69，界面加1；缺少档案的旧诊断保留默认等级1。

背景／图标／称号来自public档案3846／3850／3858，通过本版商城ID到callsign表行号映射。不能把300xx物品ID截断为10位。资源和字段事实见 `fixtures/protocol/player-card-3.3.3.3.json`。非零cardNameplate缺少已核实映射，明确拒绝。

clientState字段30／37为rank／prestige，39／40／41／42为icon／title／background／nameplate；`0x525320..0x5253c7`复制到clientInfo。`L <client> <slot>`经`0x6889c0`复制身份和装饰，回放使用slot7，前三名使用slot1..3，消费者为`0x6b0130`。两种名片共用真实参赛者资料。缓存+4是title、+8是background、+0xc是icon。

当前玩家档案为70级，背景30060、图标30059、称号30061；“新兵”是当前所选称号。Bot使用自身默认名片。
