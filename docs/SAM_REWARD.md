# SAM 防空奖励

本版 3.3.3.3 的普通奖励 21 具备资源绑定、设备部署、敌机锁定、制导导弹、碰撞判伤和对应支援撤销。阿富汗实机已确认零起始 4 杀获取、模型与 DObj、库存消费、导弹移动、命中爆炸和敌机移除；完整设备动作与声音尚未完成，不能列为完整完成。空投 SAM 22 和 Pro 条目保持独立身份，不因普通 SAM 处理器存在而视为已接入。

## 本版资源

初始化阿富汗的匹配 NCS 与只读资源捕获绑定激活武器 299 `auto_tow_mp`、模型 133 `t5_weapon_sam_turret`、伴随武器 351 `tow_turret_mp`、空中爆炸特效 5 和设备爆炸特效 78。模型使用捕获的真实边界。伴随武器定义的射速为 750ms、弹速为 3000 单位/秒、直击伤害为 1000、爆炸范围为 300、内外伤害为 300/200。弹速来自本版 WeaponDef 的偏移 0x8f4，不以其它发射器资源代替。

奖励 21 仅在模型、边界、伴随武器和特效有效时发布可用库存。4 杀门槛、权威死亡去重、普通动作槽、库存和成功消费共用连杀状态。部署失败保留库存；地面、坡度、净空、视线和人物占位检查共用设备部署流程。

## 服务端效果与协议

SAM 只锁定敌方存活航空支援。真实世界及动态物体挡住锁定视线；射线仅排除发射设备自身。EMP 暂停发射，弹药实体池已满时不启动射速计时。最近目标选择、5000 单位锁定距离、1000 点设备生命、60 秒设备期限、500ms 启动延迟和 5 秒导弹寿命为明确的本地兼容数值，不声称恢复官方 GSC 参数。

设备使用实体 384..447；SAM 导弹使用 1648..1663，与地图物体、飞机、手雷和临时冲击事件编号分离。导弹发送原生 MISSILE、注册武器、发射者、位置和俯仰/朝向，进入增量快照、删除及编号复用流程。每 20ms 子步重新朝目标中心制导并检查碰撞。直击分发至真实被撞航空实体、设备或地图物体；一次爆炸走现有特效和范围伤害流程。

锁定记录包含支援的发起者、奖励 ID、阵营、起止时间和实体编号。目标消失后导弹移除；飞机实体槽位复用不会使旧导弹获得新目标。击毁飞机只撤销其对应支援，保留其它飞机和未用奖励库存。对局结束移除导弹。SAM 受损后移除模型及碰撞，保留短暂内部状态供编号回收；红/黄色 SAM 模型未被证实为残骸，不将其冒充损毁模型。

## 验证边界

回归覆盖 MISSILE 的实体编号、归属、角度、增量和删除；制导移动、命中、一次爆炸、发射设备自身碰撞排除、其它物体碰撞、目标身份复用、容量、友军过滤、锁定遮挡、距离、EMP 和射速。资源提取回归独立验证 0x8f4 弹速读取。完整资源、诊断账号和原生采样保存于忽略目录。`sam-native-acceptance.json` 汇集本版资源、运行二进制哈希和实机证据：设备模型 133 的非零 DObj，武器 351、归属 0 的导弹 DObj，8 帧位置/方向变化，以及原生空中爆炸。敌机在发射后约 0.7 秒消失；对应服务日志记录 1000 点直击、敌机生命归零和精确支援身份撤销，消失早于该支援的自然期限。

敌机诊断通过 `acceptance_enemy_support` 安排显式的敌方 UAV/反 UAV 库存与普通调用。该配置只允许静止诊断、严格递增的 1..600 秒时刻及至多 8 次调用，资源和服务数据目录均需隔离标记。日志明确库存为诊断供应，不作为自然连杀证据；玩家奖励门槛仍独立通过真实击杀验收。诊断不写客户端内存，不修改 EXE/DLL。

设备原生转动、发射动作、连续声音、搬运及放置预览仍需补齐。GENERAL 模型或服务端伤害回归均不能代替这些表现的实机证明。
