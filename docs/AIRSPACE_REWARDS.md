# 空中连杀支援

UAV1和反UAV3的雷达效果已有原生验收，飞行实体使用匹配地图的真实模型、边界和空中爆炸特效。阿富汗实体模型分别为149 `vehicle_uav_static02_mp`、141 `vehicle_counter_uav_static02_mp`，特效为5 `explosions/aerial_explosion`。

资源准备器的 `--entities` 参数从同版本、同地图的只读实体捕获读取唯一 `airstrikeheight` 锚点，并保存来源SHA。阿富汗锚点为 `[1875.7,1261.8,1456.6]`。该位置是空袭高度基准，不是已核实的 UAV 飞行高度。UAV 与反 UAV 当前沿更高的水平直线飞过地图，不绕圈。调用前以真实模型边界检查完整航段的扫掠体积；没有净空或没有实体额度时返回原枪、保留库存。

飞机占用实体448..463，与地图物体256..383、部署设备384..447保持独立碰撞组。共有16个飞行实体额度。位置和航向进入原生GENERAL快照、ACK历史和回放；普通射击、近战及范围伤害通过世界实体分发飞机受损。友方飞机挡弹但不受友伤。击落产生一次空中爆炸并释放实体及碰撞，按调用者、奖励ID、开始和结束时刻撤销精确对应的雷达支援，不清掉其它库存或其它同队UAV。

原有支援期限为30秒。飞机生命400/500、速度200单位/秒、6000单位航段、锚点上方3000单位高度、相邻实体450单位侧向间距为当前明确的兼容参数；阿富汗当前高度为4456.6。真实资源中尚未查到原版 UAV 的精确高度、速度与路线参数，不将这些数值认作官方 GSC 规则。航向在整个航段保持不变；无完整净空时拒绝调用，不降低高度或缩回圆形路线。全局EMP会击毁敌方实体并撤销对应支援；到期、原支援撤销或对局结束都会移除飞机。旧的仅雷达资源仍可执行已有雷达效果，缺少完整模型与边界时不宣称飞行实体已接入。

阿富汗原生验收通过Rust启动器运行，使用隔离账号、零起始连杀、六个聚集静止敌人和普通窗口输入。`airspace-native-result.json`记录4次权威死亡达标、真实库存消费、模型149/141、非零原生DObj、持续移动，以及支援和飞机到期清除。运动采样共237帧，分别观察到89和145种位置，DObj槽为345/374。`sam-native-acceptance.json`另行确认敌方 UAV 的原生 SAM 制导命中、空中爆炸、提前移除及精确支援撤销。`airspace-emp-native-acceptance.json`确认零起始 15 杀获取 EMP、库存消费与敌方 UAV 的提前击毁；原生反 UAV 的 EMP 验收和普通枪弹击落仍待补。这些证据支持各自的模型、库存和击毁行为，不证明当前直线航迹或数值已与原版一致。直线轨迹的原生位置、高度和固定航向需另行验收。权威伤害、精确支援撤销和生命周期有合成回归。

`captured_air_support_anchor_has_a_clear_flight_path` 只读取被忽略的真实资源和碰撞，验证两种模型在捕获锚点具有完整净空轨道，不代替原生验收。SAM 的制导拦截和剩余设备表现见[SAM 防空奖励](SAM_REWARD.md)。攻击直升机、空袭、远控炮手和空投仍需各自的实际处理器与验收。
